<a id="implementation-differences"></a>
## 資料間・資料と実装の相違

原資料の説明と、公開されているコードから確認できる動作には以下の相違があります。研究結果を引用するときと、新たに実験するときに区別が必要です。

| 項目 | 原資料の記述 | このリポジトリでの扱い |
| --- | --- | --- |
| 75.09% の評価条件 | 卒業論文の「あらまし」では左右を「区別する」とある。本文・まとめ・概要・スライド11では「区別しない」 | 複数資料で一致する本文側を採用。左右別44.25%、左右をまとめた場合75.09%と表記 |
| モデル入力 | スライド7・8、論文「評価設計」では角度・手の左右・向き | 現行 `prepare_data()` が返す入力は20角度のみ。`rl` と `yaw` は保存するが入力には含めない |
| 出力クラス数 | モデル図と本文に「59種類」とある一方、結果表には `01r` / `01l` など左右別クラスがある | 研究対象は59手形。実装の出力数は左右を含む実際のラベル数で決まり、59種が左右とも揃えば118クラス |
| `yaw` の単位 | 論文の式は度数法 | コードは `arctan2` のラジアン値を保存。`docs/data-format.md` は実装の単位を説明 |
| ブレ除外 | 論文・概要・スライドではブレの大きいフレームをデータから除外すると説明 | コードでは角度を先に保存し、移動量による除外は座標・画像に適用 |
| 人差し指の最初の角度 | 論文本体の点の組は `(9, 5, 0)` | コードとスライド21のコード画像は `(9, 0, 5)`。本リポジトリの式・実行手順はコードを基準にする |
| 平均正解率 | 論文「評価設計」では fold ごとの正解率の平均として説明 | 現行コードはクラス別正解率の単純平均を計算する。44.25%・75.09%の集計過程は元の予測データなしには検証できない |
| Top-N の「信頼度」 | 表3・4・6・7に1を超える値があり、本文では Softmax 前の値を用いる説明もある | 表の数値を確率・百分率と解釈しない。現行コードは Softmax 後の確率を出力するため、原表のスコアと直接比較しない |
| 結果表の掲載ラベル | スライド9・11の表と卒業論文 表2・5では、掲載ラベルの一部が異なる | 結果表・CSV・グラフは卒業論文 表2・5に統一。表を混ぜて全クラスの一覧を推定しない |
| 撮影解像度 | 卒業論文では `1980×1080` と記載 | 原文どおり記載。一般的な1920×1080に読み替えず、動画メタデータは未確認とする |
| 追加の除外番号 | 現行コードは `64` も除外するが、論文 表1は01〜63 | 64の意味・除外理由は未確認。01〜63のラベル表に追加しない |

表3の `01l` の説明は「右手」となっていますが、ラベル体系上は左手です。表4の `48r` の説明も同様に左右表記が食い違っています。本文の説明では接尾辞 `r` / `l` を基準にします。表7には `43` と `27` の名称の取り違えがあり、名称の参照には表1を使います。表6の `52` のスコアは本文で3.90、表で3.89と異なるため、確率の比較グラフには用いていません。
