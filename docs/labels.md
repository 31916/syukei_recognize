## ファイル名と左右の扱い

`01` はア型、`01r` は右手のア型、`01l` は左手のア型です。動画 `t1_01.mp4` の抽出結果は `t1_01r.json` / `t1_01l.json` になります。被験者 ID は元の研究では `t1`〜`t10` ですが、現在のコードでは別の ID も使えます。

学習・fold ごとの評価は左右付きのクラスで行い、集計時に左右を同一視します。59手形すべての左右が揃った場合、学習側のクラス数は118です。実際の出力次元は入力データに存在するラベルから決まります。

`64` は現在の `EXCLUDED_LABELS` に含まれますが、論文のラベル一覧にはありません。意味や除外理由は資料から確認できないため、名称を割り当てていません。

表中の名称はこの研究のラベル体系です。あらゆる手話・辞典に共通する標準分類という意味ではありません。
