# matura_arbeit からの移行

リポジトリ名を `syukei_recognize` に変更し、処理の入口を役割が分かる名前に整理しました。整理前の実装は Git 履歴（コミット `a2812bb`）から参照できます。

| 旧ファイル | 現在のファイル |
| --- | --- |
| `detect.py` | `extract_hand_features.py` |
| `learn.py` | `training_utils.py` |
| `k1.py` | `train_cross_validation.py` |
| `k2.py` | `evaluate_models.py` |
| `k3.py` | `summarize_results.py` |
| `valuation.py` | `evaluate_models.py` に評価の入口を一本化 |

## 使い方の変更

- 固定パス `./do/data/...` を廃止し、リポジトリ直下の `data/` を既定値にしました。引数で以前のデータ置き場も指定できます。
- 評価結果の既定フォルダ名は `valuation/` から `evaluation/` になりました。
- 処理は各ファイルの `main()` から起動し、インポートだけでは学習・動画処理・ファイル保存を実行しません。
- モデル名はモデルフォルダ基準の相対名として保存します。
- 学習・評価は空の出力先を要求します。既存の実験を混ぜずに保存するためです。
- `__pycache__` を追跡対象から外し、依存関係と実行手順を追加しました。

## 不整合の修正

- 評価で標本を再抽出せず、学習時に保存した `selected_data.json` を使います。入力ファイルの列挙順は新規学習時に固定します。
- 評価対象は各 fold の検証インデックスに限定します。旧 `valuation.py` は検証インデックスを使用せず全標本を予測していました。
- Softmax 出力を「logit」と呼んでいた箇所を整理し、予測確率として保存します。旧 `top_10_logits.json` は生成しません。
- 不正な角度の標本を学習前に除外し、特徴量と正解ラベルの対応を維持します。
- 角度計算の丸め誤差と長さ0の辺を扱い、全点未検出の移動量計算で警告を出さないようにしました。
- 動画ごとに検出器を初期化・解放し、手の検出が0件でも空の特徴量 JSON を出力します。

元の `learn.py` にあった未使用のランダム分割学習関数は整理し、学習の入口を GroupKFold に統一しました。モデル構造、既定の学習条件、除外番号、左右をまとめる Top-1 集計方法は引き継いでいます。

旧出力との混在は避け、新しい出力先に学習・評価をやり直してください。標本の順序の固定や数値処理の修正があるため、旧モデルと新しい fold 情報を組み合わせることはできません。元の研究データによる精度の再現は未確認です。
